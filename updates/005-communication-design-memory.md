# GO-BUILD Update 005: Communication, Design Memory & Skill Versioning

## Version
v1.5.0

## Date
2026-09-04

## Type
Feature / Architecture / Memory System / Guidelines

## Priority
HIGH

## What changed
1. Внедрён стандарт коммуникации: русский язык как основной, обязательное краткое и естественное комментирование действий в процессе работы («что делается и зачем»).
2. Создана система долговременной памяти предпочтений пользователя `DESIGN_MEMORY.md`:
   * Фиксация похвалы пользователя (триггеры «красавчик», «круто получилось», «топ», «оставляем») с декомпозицией «что именно понравилось»;
   * Формирование **User Design DNA** (Style, Colors, Typography, Components, Layout, Visual Patterns);
   * Фиксация отвергнутых решений в Avoid-список (Negative Design Memory);
   * Декомпозиция удачного дизайна по 10 аспектам (Success Pattern Extraction);
   * Принцип анти-зацикливания (базовое направление, а не слепой шаблон) и регламент лаконичной реакции на похвалу.
3. Внедрена система обязательного версионирования скилла GO-BUILD, ведение `CHANGELOG.md` с блоком `Study / Review`, архив `updates/` и модуль `research/`.

## Why
GO-BUILD должен эволюционировать: запоминать визуальный вкус пользователя, не повторять отвергнутых ошибок, открыто и понятно коммуницировать на русском языке в процессе разработки и вести строгую хронологию собственного развития.

## New rules
* **Основной язык**: Русский язык для всех отчетов, рассуждений и вопросов (англ. термины только для технических названий и библиотек).
* **Комментирование действий**: Кратко информировать пользователя о ключевых изменениях в процессе работы («Сейчас убираю дублирование плашек...»).
* **Формула памяти**: `Design → Feedback → Extract Pattern → Remember → Apply → Improve`.
* **Реакция на похвалу**: лаконичное подтверждение («Зафиксировал. Этот паттерн считаем удачным...»).
* **Обязательный update-пакет**: каждое существенное изменение скилла обязано сопровождаться файлом в `updates/`, записью в `CHANGELOG.md` и повышением версии.
* **Не перезаписывать историю**: старые правила помечаются `Deprecated`, а не удаляются.

## Changed rules
* `SKILL.md` дополнен стандартами коммуникации, памяти и версионирования.
* Субагенты обязаны сверяться с `DESIGN_MEMORY.md` при разработке и ревью.

## Removed
* Запрещено «молчание» агента во время крупных визуальных перестроек.
