# GO-BUILD Update 004: Design & Development Resources

## Version

## Date

## Type
Feature / Resource Catalog / Guidelines

## Priority
MEDIUM

## What changed
Создан официальный каталог проверенных внешних ресурсов `references/resources.md` и регламентирован процесс работы с референсами `REFERENCE → ANALYSIS → ADAPTATION`.

## Why
Агенты должны использовать проверенные библиотеки (shadcn/ui, Lucide, Hugeicons), аудировать зависимости через Libraries.dev и исследовать дизайн-паттерны осознанно, исключая слепое копирование чужих макетов.

## New rules
* **Официальный каталог**: утверждены UI-ресурсы, инструмент аудита зависимостей Libraries.dev и доверенные дизайн-платформы (styles.repro.design, designmd.me, open-design.ai, aura.build и др.).
* **Протокол работы**: `Задача проекта → Поиск → Анализ → Определение принципов → Проверка → Адаптация → Anti-AI-Slop → Реализация`.
* **5 обязательных вопросов** перед переносом любого референса.
* **Аудит пакетов**: проверка необходимости, активности, размера бандла и лицензий перед добавлением зависимости.

## Changed rules
* Разрешено использовать дизайн-ресурсы для анализа паттернов структуры и layout при строгом запрете копирования декораций.

## Removed
* Запрещено автоматическое затягивание сторонних npm/go-пакетов без проверки на Libraries.dev.
