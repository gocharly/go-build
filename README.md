# GO-BUILD

> Инженерный стандарт и манифест разработки цифровых продуктов для AI-ассистентов.  
> Меньше шума, точный смысл, чистая архитектура.

---

### О стандарте

**GO-BUILD** решает главную проблему современного генеративного кода: избыточность. Когда нейросеть начинает додумывать интерфейс, украшать экран рамками, нагромождать абстракции и создавать файлы «на будущее» — продукт теряет фокус и чистоту.

Этот стандарт переводит разработку в режим спокойного, уверенного минимализма:
1. **Сначала смысл, потом код.** Каждая функция решает задачу пользователя, а не фантазию модели.
2. **Воздух вместо рамок.** Отступы, контраст и типографика создают иерархию естественнее, чем сплошные border-линии.
3. **Хирургическая точность.** Никакого рефакторинга соседних строк и не запрошенных кнопок.

---

### 6 фаз разработки (Rail Pipeline)

Разработка движется по детерминированному конвейеру. Агент не приступает к следующему шагу, пока не закрыт предыдущий:

```text
Scope Lock → Discovery & Reuse → Architecture & Naming → Surgical Action → Defensive Verify → Reward
```

* **1. Scope Lock** — фиксация границ задачи (`[REQUESTED]`, `[PROTECTED]`, `[REQUIRED]`, `[FORBIDDEN]`). До фиксации писать код запрещено.
* **2. Discovery & Reuse** — сначала ищем существующие функции и типы в проекте, а не плодим дубликаты.
* **3. Architecture & Naming** — называем функции строго по их действию (`calculatePrice`, `createUser`), собираем логику вокруг предметных доменов, а не свалок `utils/`.
* **4. Surgical Execution** — минимальный чистый diff, соблюдение семантики, `Border Last` и полный `Zero-Emoji`.
* **5. Defensive Verification** — автономный запуск проверок, защита от BOLA/IDOR (Data Layer Binding), экранирование и строгие схемы DTO. Никаких «запустите сами».
* **6. Reward Score** — расчет индекса инженерного качества (0–100) и лаконичный отчет.

### Архитектура репозитория

```text
go-build/
├── SKILL.md                 # Полная спецификация и системные инструкции скилла

│   ├── README.md            # Навигатор по справочникам

│   ├── defensive-architecture-and-security.md # Zero-Trust валидация и защита от инъекций
│   ├── universal-ui-layout-and-visual-discipline.md # Правило Border Last, отступы и типографика
│   ├── universal-modularity-and-code-simplicity.md  # Main File Principle и простота
│   └── cross-platform-window-adaptivity.md    # Адаптивность окон для Web и Desktop
├── research/                # База исследований архитектур и паттернов

└── updates/                 # Журнал развития и версионирования стандарта
```

### Подключение

Для работы в Google Antigravity или любом другом AI-окружении достаточно добавить директиву в глобальный или проектный `GEMINI.md` / `AGENTS.md`:

```markdown
Для ВСЕХ задач разработки и программирования агент обязан активировать и строго соблюдать архитектурный стандарт из скилла go-build (~/.agents/skills/go-build/SKILL.md).
```
