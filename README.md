# GO-BUILD

Помощник для вайбкодеров. Чтобы писать код с нейросетями в кайф — без каши в архитектуре, без лишних файлов и без визуального мусора.

Когда пишешь код через промпты, нейросети часто увлекаются: дробят 20 ненужных файлов ради простой кнопки, обводят всё серыми рамками, вставляют неуместные эмодзи и молча переписывают соседние куски кода. Приходится тратить кучу времени на чистку.

**GO-BUILD** ставит AI-ассистента на правильные рельсы: он помогает сразу выстроить понятную структуру проекта и писать только то, что реально нужно.

---

### Что дает скилл

- **Понятная архитектура с первого дня.** Код раскладывается по смыслу, а не сваливается в бесконечные `utils` и `helpers`. В проекте легко ориентироваться даже через месяц.
- **Чистый визуал со вкусом.** Никаких рамок ради рамок, лишних теней и детских эмодзи. Интерфейс дышит за счет отступов и аккуратной типографики.
- **Никакой отсебятины.** Ассистент делает ровно то, о чем его попросили, и не ломает соседний работающий код.
- **Поиск перед созданием.** Модель сначала смотрит, что уже есть в проекте, и переиспользует это, а не плодит клоны функций.
- **Автономность.** Тесты и запуск агент берет на себя, а не скидывает простыни команд в чат.

---

### Как это устроено

Перед тем как трогать файлы, агент проходит простую цепочку:

1. **Зафиксировать задачу** — понять, что делаем, а что категорически не трогаем.
2. **Найти готовое** — проверить существующие функции и компоненты в проекте.
3. **Дать нормальные имена** — называть функции по действию (`calculatePrice`, а не `doStuff`).
4. **Сделать точечно** — написать минимальный код без лишней шелухи.
5. **Проверить самому** — убедиться, что проект собирается и тесты проходят.
6. **Показать результат** — коротко отчитаться по делу и оценить чистоту работы.

### Быстрый старт

Установить одной командой через `npx`:

```bash
# В текущий проект
npx @gocharly/go-build

# Или глобально для всей системы (Antigravity, Claude Code, Cursor)
npx @gocharly/go-build -g
```

*(Также доступна короткая команда: `npx go-build` или `npx go-build -g`)*
